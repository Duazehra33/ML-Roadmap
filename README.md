# Machine Learning – Week 01
## Introduction to Machine Learning & Fundamentals

###  Overview
This repository contains the theoretical concepts and practical implementations covered in **Week 1 of Machine Learning**. It focuses on understanding the fundamentals of Machine Learning, its types, workflow, data exploration, regression algorithms, and model evaluation.

The repository includes a theoretical roadmap in PDF format, practical Jupyter Notebooks, and CSV datasets used for implementing and experimenting with Machine Learning algorithms.

##  Repository Contents

### 1. `Week 1 ML Roadmap.pdf`
**Theory & Conceptual Understanding**

This PDF covers the foundational concepts of Machine Learning, including:

- Introduction to Machine Learning.
- Types of Machine Learning:
  - Supervised Learning
  - Unsupervised Learning
- Machine Learning Workflow:
  - Problem Definition
  - Data Collection
  - Data Preprocessing
  - Model Training
  - Model Evaluation
  - Deployment
- Bias-Variance Tradeoff.
- Exploratory Data Analysis (EDA).
- Gradient Descent and its types (Batch, Stochastic, etc.).
- Overfitting and Underfitting.
- Model Evaluation Metrics:
  - Accuracy
  - Precision
  - Recall
  - F1-Score
  - Mean Squared Error (MSE)
  - R² Score

##  How to Run

1. Clone or download the repository.

2. Navigate to the project directory.

3. Install the required libraries:

   ```bash
   pip install numpy pandas matplotlib seaborn scikit-learn jupyter
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the required `.ipynb` file and execute the cells sequentially.

**Note:** Keep the CSV dataset files in the same directory as their respective notebooks to ensure correct file loading.
